# Internationalization

**Read this when:** adding any user-facing string, formatting a number or date, or
adding a language.

## The rule

**No string a user can read may originate outside `src/locales/en`.** An ESLint error,
not a convention.

It covers JSX text, `placeholder`, `title`, `alt`, `aria-label`, `aria-placeholder`, and
`toast.*()` arguments. Restricting JSX text alone is the common half-measure — it catches
`<p>Save</p>` and misses `aria-label="Close"`, which is how the accessible copy becomes
the only untranslated copy in the app.

Tests and e2e specs are exempt: their literals are fixtures, and a spec asserting only on
`t.*` could not catch a key pointing at the wrong string, since both sides would move
together.

## Never build a string by hand

| Instead of                   | Use                                     |
| ---------------------------- | --------------------------------------- |
| `` `${n} widgets` ``         | `plural(n, t.widgets.list.resultCount)` |
| `` `Showing ${a} of ${b}` `` | `format(t.common.showingOf, { … })`     |
| `d.toLocaleDateString()`     | `formatDate(d)`                         |
| `` `$${cents / 100}` ``      | `formatCurrency(cents)`                 |

A template literal is untranslatable, and `+ 's'` is already wrong at `n === 1`.
Pluralization is a property of the language: English has two forms, Polish four, Arabic
six. `plural()` uses `Intl.PluralRules` rather than `count === 1` so adding a language
stays a content change.

`formatCurrency` takes **minor units** (cents). Binary floats cannot represent most
decimal amounts exactly, and money off by a cent is a bug someone has to reconcile.

## `as const` is load-bearing

Without it every value widens to `string`, `Translations` stops distinguishing keys, and
a locale missing half the catalog satisfies the type — the compile-time guarantee
disappears silently.

## Adding a language

A content-only change:

1. `cp -r src/locales/en src/locales/es`
2. Translate the values; leave every key exactly as it is
3. Add `'es'` to the `Language` union and the `translations` map
4. `npx tsc --noEmit`

`Translations = typeof en`, so a missing, misspelled, or extra key is a **compile error**,
not a blank string found in production. That no component, hook, or route changes is the
acceptance criterion — [ADR-0013](../adr/0013-static-typed-locales.md).

`src/config/language.ts` is the single switch: it seeds `DEFAULT_LANGUAGE`, `LOCALE_TAG`
for every `Intl` formatter, the `Accept-Language` header on both axios clients, and
`<html lang>`.

Note that `date-fns` locale objects are separate from the catalog — swap the `locale`
constant in `DateRangePicker` too.

## No em-dash in visible copy

It reads as machine-written. Rephrase rather than substituting another separator (`·`,
`-` are the same tic in a different costume): split the sentence, use a colon, or reword.
Also lint-enforced. Code comments are unaffected.
